# Local v0.1 Release Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a dependable Docker-first `v0.1.0` for 100–1,000-document local corpora on `linux/amd64` and `linux/arm64`.

**Architecture:** Preserve the single Bun application, libSQL, local blob store, parser subprocess, and embedding worker. Add only release tooling, evaluation, recovery verification, actionable failures, scale measurement, and user documentation around those existing boundaries.

**Tech Stack:** Bun 1.3.13, TypeScript 7.0.2, React 19, libSQL/FTS5/vector indexes, AnyDoc 0.2.4, local Transformers.js MiniLM, Docker Buildx and Compose.

**Spec:** `docs/superpowers/specs/2026-09-05-local-v0.1-polish-design.md`

## Global Constraints

- One local container and one persistent volume; originals remain canonical.
- Publish one image reference containing native `linux/amd64` and `linux/arm64` images.
- Parsing remains a subprocess; embedding remains a worker thread and works offline after build.
- Preserve REST, MCP, and dashboard compatibility.
- Retrieval changes require committed evaluation evidence.
- Never expose secrets, content, embeddings, internal absolute paths, or stack traces.
- Exclude PostgreSQL, S3, distributed deployment, Kubernetes, webhooks, multi-tenancy, hosted AI, reranking, chat, OCR infrastructure, continuous watching, and large observability systems.
- Every milestone ends with `bun run typecheck` and `bun test` green.

## File Map

- `Dockerfile`, `compose.yaml`, `.dockerignore` — reproducible single-container distribution.
- `scripts/healthcheck.ts`, `apps/server/src/shutdown.ts` — health and graceful lifecycle.
- `scripts/release/{http,smoke}.ts` — HTTP/MCP acceptance harness.
- `scripts/release/{test-platforms,publish,check}.sh` — architecture and release gates.
- `packages/core/src/ingestion-failure.ts` — safe public ingestion errors.
- `apps/server/src/ui/lib/ingestion-error.ts` — recovery actions for error codes.
- `tests/retrieval/{evaluator,recall.test}.ts` plus corpus JSON — quality evaluation.
- `tests/integration/{backup-restore,job-recovery}.test.ts` — data recovery proof.
- `scripts/{backup-volume,restore-volume}.sh` — stopped-volume recovery commands.
- `scripts/scale/{lib,run}.ts` — reproducible scale measurement.
- `README.md`, `SECURITY.md`, `CHANGELOG.md`, `docs/*.md` — release guidance.

- [ ] Implement `shutdown.ts`:

```ts
export function createShutdownHandler(input: {
  stopApp: () => void;
  stopServer: () => void | Promise<void>;
}): () => Promise<void> {
  let stopping: Promise<void> | undefined;
  return () => stopping ??= (async () => {
    input.stopApp();
    await input.stopServer();
  })();
}
```
